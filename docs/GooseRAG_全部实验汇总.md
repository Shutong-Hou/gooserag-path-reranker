## 0. 一句话结论

一个 **0.19B、无外部 LLM、无 transductive 实体表** 的 KGQA 系统：
- WebQSP test H@1 = **58.0%**（n=1627）/ 58.5%（n=1615，5 seed 均值 0.5846±0.0035）
- MetaQA test H@1 = **88.0%**（全量 14,274 题；子集 88.2%）
- 单题 **278ms**（beam 73 + 打分 205，按题批量）/ 2.2GB；逐候选串行上界 3.9s
- 其判定器可作为**可插拔重排层**，把 RoG-7B 的候选 H@1 从 60.9% 提到 **66.1%（+5.16pt, p=8.5e-7）**，插入成本仅 **+26ms/题（批量；串行 +428ms）**

**不主张**：新架构、SOTA、Pareto 最优。NSM（110M/68.7%）在参数量-精度上支配我们；CWQ 上路径信号失效。

## 3. 实验总表（E01–E24）

> 性质标注：**确认** = 配置由 val/预注册决定、test 只评一次；**探索** = 在 test 上找过方向，不得进主表。

### 第一阶段：基线、集合重排、关系头（E01–E08）

**E01 基线（plain verifier）**
- 目的：确立可复现基线
- 配置：walker + listwise 判定器，无路径、无二阶头
- 结果：H@1 **0.4419**（s42）；3 seed 均值 **0.4390**
- 性质：确认 ｜ 产物：`e2e_plain_base.json`

**E02 SetRank（默认候选池，5 seed）**
- 目的：验证"复用判定器隐状态做集合重排"
- 配置：768 维隐状态 + 5 维特征 → d=256/2 层/8 epoch，预注册不做 val 选优
- 结果：**0.4944 ± 0.0027**
- 性质：确认 ｜ 备注：早期 d384/8ep/20ep 的 0.5480/0.4898/0.4799 是未预注册挑配置，已弃用

**E03 VGHN 路径头 + SetRank（5 seed）**
- 结果：**0.5393 ± 0.0050**
- 性质：确认 ｜ 即"关系头挖矿"带来的召回提升

**E04 max-children 调参（128/256/512）**
- 结果：H@1 全部 **0.4419**，in_cand 全部 0.7548
- 结论：**完全无影响**——此前"24.5% miss 源于子节点截断"的归因**作废**
- 性质：探索 ｜ 产物：`e2e_mc256.json`、`e2e_mc512.json`

**E05 path-aware verifier（核心发现）**
- 目的：判定器是否丢掉了路径信息
- 配置：prompt 改为 `Question / Relation path / Candidate`，2,072 组 / 36 万候选（正例率 2.63%），2 epoch
- 结果：H@1 **0.5323（+9.04pt）**，H@5 0.6663，**in_cand 不变 0.7548**
- 结论：提升 **100% 来自排序，非召回**
- 性质：确认（单变量）｜ 产物：`e2e_path_base.json`、`verifier_ft_webqsp_rwkv7_listwise_path_s42.pt`

**E06 path verifier + SetRank（默认头）**
- 结果：0.5418（H@5 0.6718）；相对 E05 仅 +0.95pt → 两个排序组件高度重叠

**E07 完整系统（VGHN + path + SetRank）**
- 结果：**0.5765**（H@5 0.7090 / H@10 0.7418，n=1615）

**E08 SetRank 消融（s42）**
| 配置 | H@1 | Δ |
|---|---|---|
| full | 0.5418 | — |
| `--no-enc`（去跨候选注意力） | 0.5412 | −0.06pt |
| `--no-h`（去隐状态） | 0.4737 | **−6.81pt** |
| `--no-f`（去 5 维特征） | 0.5399 | −0.19pt |

- 结论：**集合交互几乎无贡献；隐状态复用才是主要来源**

### 第七阶段：同参数量对照与两个止损（E26–E28）

**E26 同参数量 Transformer 对照（P0-2，强结果）**
- 设置：**同一份候选池**（`mined_webqsp_test_vghn.jsonl`，n=1627）、同一 prompt、同一训练配方（2 epoch / lr 1e-5 / max-cands 64 / batch-groups 1），只换主干

|---|---|---|---|
| **RWKV-7-Goose** | 191M | **0.5550** | 0.6988 |

| Pythia-160M | 160M | 0.4628 | 0.6411 |

- 结论：同参数量下 RWKV **+7.1pt（vs GPT-2）/ +9.2pt（vs Pythia）**
- 诚实说明：RWKV-7-Goose 预训练语料更大（2.8T tokens），差异不纯是架构；但足以回答"为什么不用现成小 Transformer"

**E27 RPO 式关系头（止损门触发，负结果）**
- 做法：hard-frac 0.2 → 0.3 重建难负例，重训 VGHN 头

**E28 topk-rel=25（负收益）**

- 对照 topk15 的 5 seed 均值 0.5760 → **低 0.47pt**；早期 +0.37pt 是噪声
- 结论：管线参数已到平台

- 最终系统 H@5 ≈ **71.9%**

### 4.2 同池单变量（n=1615，唯一变量=排序函数）
walker 17.8 → plain 42.0 → **path 55.9** → +SetRank 57.6 → 微调 **58.5**

**同数据孪生对照（定稿口径，唯一变量=prompt 里有没有路径）**

### 4.6 成本
| 项目 | 我们（整套） | 插入到 RoG（重排层） |
|---|---|---|
| 参数 | 191M | 191M（额外） |
| 延迟（按题批量，主口径） | **278 ms/题**（beam 73 + 打分 205，200 候选） | **+26 ms/题**（15.7 候选） |

| 显存 | 2.2 GB | +2.2 GB |
| 外部 LLM | 无 | 无（底座仍需自身成本） |

- **口径修正**：旧的 485.7 ms / +98.5 ms 是混合口径、不可复现，已弃用；上表为单一 harness 实测

- **重要澄清**：可插拔**不会**降低底座成本；"成本 1/4"只适用于"用我们整套替换 LLM"

## 8. 当前论文定位与贡献

**定位**：可插拔的关系路径重排层（不是"更强的 KGQA 模型"，不是"新架构"）

| # | 贡献 | 证据 |
|---|---|---|
| C1 | 关系路径条件化是排序主信号 | **同数据孪生**：WebQSP +8.1（p=2.1e-10）/ MetaQA +34.5（p=6.2e-142） |
| C2 | 跨检索器可迁移（walker→RoG-7B） | +5.16pt，p=8.5e-7；beam10 +18.9pt |
| C3 | 极低插入成本 | +26ms/题（批量）/ +428ms（串行）、+2.2GB、无 LLM |
| C4 | 失败边界可判据化 | CWQ 正例率 1.07% → 失效；零样本跨数据集失效 |
| C5 | 端到端系统 | 0.19B / 278ms / 2.2GB / 58.0% |

**Limitations（必须写）**
1. 精度被 NSM 支配（110M/68.7%）
2. 不是新架构（无新模块/新算子）
3. CWQ 失效（正例稀疏）
4. MetaQA 偏容易（gold_in_cand≈99.8%）
5. 插入成本非零（+26ms 批量 / +428ms 串行，不能说"零成本"）
